# Exam Result Predictor

A responsive, static website built with HTML, CSS, and JavaScript. It estimates a possible score range from the marks and study details entered by the student, then provides study suggestions.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — prediction and validation logic

## Publish on GitHub Pages
1. Open your repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` from this folder (you can also upload `README.md`).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
7. Wait for the Pages deployment to finish, then open the website link and refresh.

## Important
This is a demo/educational estimate, not an official exam result and not a guarantee of marks. All calculations run in the browser; no student data is sent to a server.
